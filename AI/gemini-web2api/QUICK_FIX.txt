NGUYÊN NHÂN:
  Thiếu cookie authentication để upload ảnh lên Google Gemini

GIẢI PHÁP NHANH (3 BƯỚC):

┌──────────────────────────────────────────────────────────────────────────────┐
│ BƯỚC 1: LẤY COOKIE                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Cách 1 (Tự động):
    cd m:/ERP/AI/gemini-web2api
    python extract_cookie.py

  Cách 2 (Thủ công):
    1. Mở Chrome → https://gemini.google.com → Đăng nhập
    2. F12 → Application → Cookies → gemini.google.com
    3. Copy: __Secure-1PSID, SAPISID, HSID, SSID, APISID, SID
    4. Tạo file cookie.txt:
       __Secure-1PSID=xxx; SAPISID=xxx; HSID=xxx; SSID=xxx; APISID=xxx; SID=xxx

┌──────────────────────────────────────────────────────────────────────────────┐
│ BƯỚC 2: CẤU HÌNH                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

  Mở: m:/ERP/AI/gemini-web2api/config.json
  Thêm: "cookie_file": "cookie.txt"

  Ví dụ:
  {
    "port": 8081,
    "cookie_file": "cookie.txt",
    "log_requests": true
  }

┌──────────────────────────────────────────────────────────────────────────────┐
│ BƯỚC 3: RESTART SERVER                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

  Ctrl+C (dừng server)
  python -m gemini_web2api.server (khởi động lại)
